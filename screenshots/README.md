# Скриншоти для README

Сюди покладіть скриншоти у форматі PNG. Вони вже підключені до головного `README.md` відносними посиланнями:

| Файл | Зміст |
|---|---|
| `01-main.png` | Головний екран CRM |
| `02-settings-local.png` | Модалка налаштувань, обрано «Локальна SQLite» |
| `03-settings-turso.png` | Модалка налаштувань, обрано «Turso (хмарна)» з полями URL і токена |
| `04-sync.png` | Модалка з успішним повідомленням про синхронізацію |
| `05-filter.png` | Список, відфільтрований за статусом |

Просто замініть заглушки `{{ опис }}` у README — посилання вже вказують на ці файли.
